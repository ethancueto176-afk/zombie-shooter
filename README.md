# Zombie Outbreak: Boss Protocol

A top-down zombie shooter that runs in your browser. One file, no install, no dependencies.

## Play

Open index.html in any browser.

## Controls

- WASD or arrow keys to move
- Mouse to aim, hold click to shoot
- R to reload, P to pause

## What's in it

- Endless waves that keep getting bigger
- Runners from wave 3, tanks from wave 4
- A boss fight every fifth wave (THE BUTCHER, ROT KING, GRAVE LORD, THE ABOMINATION, DEATHBRINGER)
- Power-ups: health, rapid fire, shotgun mode
- Score, screen shake, particles, retro sound effects
